SGX545 GPU test stick for Intel Cedarview (GMA 3600/3650), live Debian 13

Boot a Cedarview computer from this stick. The test runs by itself for about ten
minutes, shows a desktop for part of it, and never writes to the computer's own
disks.

When it finishes, a file named results-kitv3-....tar.gz appears on this drive.
Attach that file to the GitHub issue, as the guide says:
https://github.com/The1TrueJoe/sgx545-ce/blob/um-re/docs/TESTING-CEDARVIEW.md
