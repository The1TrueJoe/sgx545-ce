SGX545 GPU test stick for Intel Cedarview (GMA 3600/3650)

Boot a Cedarview computer from this stick. The test runs by itself, only reads
from that computer, and never writes to its internal disk.

When it finishes, a file named results-....tar.gz appears on this drive.
Send that file to us as the guide says:
