# SGX530 stage 1, ninth attempt: the PDS keeps re-running the event program, no task starts

**Board:** our OMAP3630 test board, our kernel on the SD (7.3.3, the 02:16 build). 75 °C
before, 73.5 °C after.

**What ran:** powervr_sgx from sgx530 04794d77 (CI: omap3630 43153697427, powervr-sgx and
upstream green), `allow_unisolated=1 code_base_probes=1 stage1_sweep=1`, with the
code-base probe image `sgx530_probe` (fa39d633…, event program at code offset 0xd020).
- The baseline is the eighth attempt's: TI's layout, the kicker increment, 0x0a68 as an
  offset, 24 temporaries.
- The code-base probes were mapped at 0x001d8000 << k for k = 0-6 (units of 1-64 B).
- Each of the 13 variants logs `PDS_PC_BASE` every 10 ms for 100 ms.

- `EVENT_TIMER` stayed 0 in every variant: no ladder value and no probe value.
- `sweep: no variant runs the diagnostic ladder`.
- No "not independent" warning.
- Init, version, wait and heartbeat all 0, and the probe failed with -ETIMEDOUT.
- All five modules unloaded and the ti-sysc parent runtime-suspended.

**Facts (C):**
- **`PDS_PC_BASE` doesn't sit still.** Within 100 ms it returns to the same few values
  again and again, with 0 in between: the PDS keeps starting programs and going idle.
- **The values follow the event program.** With this image (event program at 0xd020)
  they are 0x50340c and 0x503410. With the diagnostic image (event program at 0x4340,
  eighth attempt) they were 0x5010d4 and 0x5010d8. The second value is the 0xf35c
  family here, 0xf75c with the diagnostic image.
- **No task started at any probed code-base unit (1-64 B), nor at our image.** No
  `EVENT_TIMER` mark.

**What it suggests (D/G):**
- **D:** as dword addresses relative to `PDS_EXEC_BASE`, 0x50340c × 4 = 0x0140d030, the
  probe image's event program (offset 0x0140d020) + 0x10, its first instruction. 0x503410
  is the next one. So the PDS runs our event program over and over.
- **G:** the PDS re-running the event program while no USSE task ever starts fits a DOUTU
  the USSE refuses or never accepts, so the PDS retries. It also fits an event that keeps
  firing.
- **The 0xf35c/0xf75c values (×4 = 0x3cd70/0x3dd70) are U.** They move by 0x1000 between
  the two images.
- None of the 12 changes to the hand-off (event data, DOUTU word 1, the interleave, the
  data master, 4 or 0 temporaries) lets a task start.
