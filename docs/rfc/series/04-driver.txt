drm/powervr_sgx: Add a driver for PowerVR SGX5xx GPUs

A render-only DRM driver for the PowerVR SGX5xx (Series5) GPUs. It runs
the SGX545 of the Intel Atom CE5300, where the GPU is a PCI function of
its own (8086:089b), and of Cedarview (GMA3600/3650), where gma500
publishes it as an auxiliary device.

- A core table names each supported core: its ID, the registers that
  move between SGX5xx cores, features, instruction set, directory lists
  and init script, and per part its revision, clock and firmware file.
  The bus says which core to expect; anything not in the table is
  refused before a register write.
- The GPU runs a microkernel on its shader unit, loaded with
  request_firmware(). The driver loads only an image that declares
  secure mode, in which no client page directory maps the firmware's
  memory.
- drm_gpuvm VMs, one page directory each; GEM shmem objects below
  4 GiB; drm_sched with one job on the GPU at a time; syncobjs and
  implicit sync on shared buffers; dma-buf export and import.
- Render jobs are built in the kernel from the client's checked command
  streams. One parameter buffer serves every client.
- A job that runs past its timeout resets the GPU. Only its context is
  guilty, the others are innocent, and a devcoredump is taken.
- Runtime and system PM: the microkernel powers off when the GPU is
  idle and before a system suspend, and starts again after.
