# GL 3 driver work on hardware: instancing gate, baselines, 4x MSAA, H1 and H2

2026-11-11, a CE5300 board, RAM boot of powervr_sgx's wip/msaa4-kcalc
4249037c (uAPI rev 3 with the samples field), open microkernel eb484b2
(features 0x2). Mesa from claude/gl3-driver-850ecf e3201b0f (x86_64 for
dEQP and `sgx_hwt`, x86_64-gl for piglit), through drive-deqp.py with
`--boot ramboot`. The kernel image, the modules and `/proc/version` were
checked against the build artifact before the run. The normal boot was
restored afterwards.

- **Instancing and primitive restart gate** (39 piglit tests): 30 pass, 7
  skip, 2 not built, 0 fail.
- **dEQP-GLES2**: 78 fail, 16638 pass, 445 skip, 4 warn. It matches the rev 3
  baseline test for test (0 status differences) and has 0 wedges.
- **Fixed-function piglit list** (340): 0 crashes, down from 5, with 87 fail
  and 176 pass. Two tests went from skip to fail (`fbo-alphatest-nocolor`,
  `-ff`: depth-only framebuffers aren't drawn). **GL 2.1 list** (275 tests):
  14 fail → pass, 9 crash → pass, 7 crash → fail. 12 skip → fail are the
  `depthstencil-default_fb-* samples=2/4` tests. They now get a 4x
  framebuffer and fail on the depth/stencil resolve, which isn't done ("sgx:
  depth/stencil blit from a 4x buffer not done").
- **4x MSAA**: `mesa/tests/sgx_msaa.c` colour and depth pass at 720×480 and
  256×256. The scaled case was a test error (a GL_LINEAR scaled resolve
  is GL_INVALID_OPERATION) and is fixed, not yet rerun. piglit
  `ext_framebuffer_multisample`: 4 pass, 4 fail, 148 skip, for want of
  ARB_framebuffer_object (docs/GL3.md, Status).
- **H2** (`hwt_fmt`, 135 tests): no fault. 0x12 returns raw 32-bit words, and
  0x0e is RGB10_A2 returned as four 16-bit channels in two registers. Table
  in docs/GL3.md.
- **H1** (`hwt_mrt`, `hwt_mrt2`): an end-of-tile program with a non-final
  PBE emit hangs the GPU, whatever the targets. RT2 alone works. There were
  three GPU resets in all, each recovered by the job timeout, and the box
  never wedged.

Raw output: `tools/isa/hwt_out/open/hwt_fmt.txt`, `hwt_mrt.txt`.
